# 특장 매매 및 구조변경 계약서 — 템플릿 데이터 계약

> 템플릿: `contract-template.docx` (STEGO_K1_특장매매계약서_템플릿.docx)
> **렌더 환경: LibreOffice 전용** (`soffice --headless --convert-to pdf`)
> 총 4페이지 / 1페이지=계약 정보·서명, 2~4페이지=계약조항(2단, 원본 그대로 · **수정 금지**)

---

## 1. 렌더 방식 (LibreOffice)

```bash
# 1) 토큰 치환된 docx 생성 (python-docx)
# 2) PDF 변환
soffice --headless --convert-to pdf contract_filled.docx --outdir <출력경로>
```

⚠️ **주의사항**
- 서버에 **한글 폰트 필수** (없으면 깨짐). Noto Sans KR / 맑은 고딕 계열 설치 확인.
- soffice 동시 실행 충돌 방지: `-env:UserInstallation=file:///tmp/soffice_<uuid>` 로 프로필 분리하거나 큐로 직렬화.
- **출력 PDF 파일이 열려있거나 잠겨있으면 덮어쓰기 실패**(`Operation not permitted`)하고 옛 파일이 남는다. 매번 새 경로에 쓰거나 변환 전 삭제할 것.
- 변환 후 `pdfinfo`로 **페이지 수 4** 확인.

## 2. 치환 토큰

### 계약 정보 (표 1)
| 토큰 | 내용 | 예시 |
|---|---|---|
| `{{contract_no}}` | 계약번호 | 2026-0001 |
| `{{contract_date}}` | 계약일자 | 2026-08-06 |
| `{{contract_party}}` | 계약처 | 영업점/대리점명 |

### 매수인 정보 (표 2)
| 토큰 | 내용 |

| `{{buyer_regno}}` | 생년월일(사업자번호) |
| `{{buyer_address}}` | 주소(사업자주소) |
| `{{buyer_tel}}` | 전화번호 |
| `{{buyer_mobile}}` | 휴대폰 |
| `{{buyer_email}}` | E-mail |

### 특장 사양 (표 3) — 견적 옵션 선택값과 1:1
| 토큰 | 내용 | 값 예시 |
|---|---|---|
| `{{spec_body}}` | 탑 종류 | 냉장/냉동, 내장 |
| `{{spec_height}}` | 탑 높이 | 저상, 표준 |
| `{{spec_spoiler}}` | 스포일러 | O, X |
| `{{spec_temp}}` | 온도기록계 | O, X |

| 토큰 | 내용 |
|---|---|

| `{{receipt_year}}` | 영수증 연도(기본 현재 연도) |

## 3. 채우지 않는 항목 (수기/서명용)

아래는 **회색 텍스트로 비워둠** — 고객이 직접 기입하거나 전자서명이 들어갈 자리:
- 영수증 서명란: 자필성명 · 서명 · (인)
- 개인정보동의 서명란: 자필성명 · 서명 · (인)
- 매수인 서명란: 자필성명 · 서명 · (인) / 회사명 · 대표이사 · (인)

매도인(이브이앤솔루션·대표이사 민원기·주소)은 **고정값**이라 토큰 없음.

## 4. 모두싸인 연동 시 (선택)

전자서명으로 갈 경우 anchor 텍스트로 활용:
- `자필성명` / `서명` / `(인)` 이 이미 문서에 있으므로 그대로 anchor 지정 가능
- 단 같은 텍스트가 3곳(영수증·개인정보·매수인)에 반복되므로, 모두싸인의 **중복 매칭 시 자동 넘버링**을 이용하거나 anchor를 더 구체적으로 지정할 것

## 5. 레이아웃 유지 규칙 (건드리면 깨짐)

- **2~4페이지 계약조항은 절대 수정 금지** (2단 섹션 구조. 섹션 경계 문단을 지우면 2단이 풀림)
- 1페이지 표들은 매수인 표 규격 기준: 너비 17520 dxa, 들여쓰기 282
- 서명란은 모두 **일반 표**(텍스트박스 아님) — 텍스트박스로 되돌리면 겹침 재발
- 값이 길어지면 1페이지가 2페이지로 밀릴 수 있음 → 렌더 후 **페이지 수 4** 검증 필수
- 특히 `{{special_terms}}` 가 길면 밀림. 2줄 이내 권장.

## 6. 검증 체크리스트

1. 페이지 수 4 (`pdfinfo`)
2. 한글 깨짐 없음
3. 1페이지에 매도인/매수인 서명란까지 포함
4. 토큰 미치환(`{{`) 잔존 여부 검사
5. 2페이지가 "계 약 조 항"으로 시작하고 2단 유지
