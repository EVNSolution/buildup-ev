# 구조변경 서류 자동생성 — 변수·수식 설계

> 목표: 플래닝고가 옵션별로 주는 치수를 **변수**로, 나머지는 **DB 상수**로 두고,
> 서류의 모든 기입값을 변수+상수의 **수식**으로 산출한다. 하드코딩 금지.
> 정답지: `ozprint(1083-2026-E9721)` 오픈베드→냉동 표준탑 여닫이 4도어 (실물 통과).

---

## 1. 입력 변수 (플래닝고 제공, 옵션 선택별로 달라짐)

| 변수 | 의미 | E9721 예시 |
|---|---|---|
| `L_in, W_in, H_in` | 하대 **내측**치수(mm) | 2420, 1790, 1480 |
| `L_all, W_all, H_all` | 차량 **전체**치수(mm) | 5040, 1895, 2400 |
| `L_out, W_out, H_out` | 적재함 **외측**치수(mm) — **무게계산 전용** | 2590, 1910, 1590 |
| `body` | 냉동 / 내장 | 냉동 |
| `doorType` | 여닫이 / 슬라이딩 | 여닫이 |
| `doorAdd` | 4도어(운전석측 추가) 여부 | true |

## 2. DB 상수 (`weight_constant` 테이블 — 관리자 CRUD, 숫자만 바꾸면 재계산)

### 2-1. 차종 기준값
| key | 값 | 단위 |
|---|---|---|
| `wheelbase` (WB) | 2995 | mm |
| `curb_base_front` | 1105 | kg (오픈베드 공차 전축) |
| `curb_base_rear` | 800 | kg (오픈베드 공차 후축) |
| `curb_base` | 1905 | kg |
| `gvw` | 2635 | kg |
| `gvw_limit` | 2680 | kg (제작허용총중량) |
| `hadae_offset` | 35 | mm |

### 2-2. 항목별 무게·위치 (후축까지거리 기준)
| 항목 | 무게 | 후축까지거리 | 비고 |
|---|---|---|---|
| 데크 탈거 | `deck_w` = 300 | `deck_d` = 35 | 확정(실측) |
| 냉동기 설치 | `reefer_w` = 50 | `reefer_d` = -300 | 확정. **탑무게와 분리** |
| 탑 설치 | **계산값**(§3) | `top_d` = 35 (=offset) | 서류상 550은 참고만 |
| 정원 | `crew_w` = 130 | `crew_d` = 1850 | 실물정답지 |
| 적재 | `max_payload`(§4) | `cargo_d` = 35 | |

### 2-3. 타이어
| key | 값 |
|---|---|
| `tire_spec` | 215/65R16 |
| `tire_allow` | 850 kg |
| `tire_wheels` | 2 (축당) |

### 2-4. 탑무게 수식 상수 (top-weight.ts → DB 이관)
면적밀도(패널 5.22냉동/5.02내장), 바닥 다층밀도, 가드 선밀도, 프레임 단중(5.14/2.33/0.71)+여백, 하드웨어 9.3, etc 10, 슬라이딩 가산 10/도어.
**⚠️ `reefer` 항은 제거** — 냉동기는 별도 설치항목(2-2)으로만 계산.

## 3. 탑무게 수식 (냉동기 제외)

`top_w = calcTopWeightKg(L_out, W_out, H_out, {body, doorType, doorAdd})` — 단, reefer 항 제외.

검증: 냉동/여닫이/4도어, 2590×1910×1590 → **407.1 kg** (총 467.1 − 냉동기 60).
※ 실물 서류는 550kg(더 무겁게 제작). 자동생성은 항상 계산값 사용.

## 4. 서류 기입값 수식

기여 함수 (W=무게, d=후축까지거리):
```
front(W,d) = W · d / WB          # 전축 기여
rear (W,d) = W · (WB − d) / WB   # 후축 기여
```

### 제원(대비표·하중계산서)
```
차량중량_후   = curb_base − deck_w + top_w + reefer_w
최대적재량_후 = floor( (gvw_limit − 차량중량_후 − crew_w) / 50 ) × 50   # 50단위 내림
              # 오픈베드: floor((2680−1905−130)/50)×50 = 600 ✓
              # E9721   : floor((2680−2205−130)/50)×50 = 300 ✓
차량총중량    = gvw (불변)
전체높이_후   = H_all,  하대(내측)_후 = L_in/W_in/H_in
하대옵셋트    = hadae_offset (불변)
```

### 공차시 하중분포 (튜닝후)
```
공차_전축 = curb_base_front − front(deck_w,deck_d) + front(top_w,top_d) + front(reefer_w,reefer_d)
공차_후축 = curb_base_rear  − rear (deck_w,deck_d) + rear (top_w,top_d) + rear (reefer_w,reefer_d)
```

### 적차시 하중분포 (튜닝후) = 공차 + 정원 + 적재
```
적차_전축 = 공차_전축 + front(crew_w,crew_d) + front(max_payload_후, cargo_d)
적차_후축 = 공차_후축 + rear (crew_w,crew_d) + rear (max_payload_후, cargo_d)
```
※ 전축 추가하중 5kg 올림(cyberts 방식)은 TS 엔진 규칙 그대로 적용.

### 판정값
```
조향륜하중분포율(%) = 적차_전축 / gvw × 100
타이어부하율(%)     = 축하중 / (tire_allow × tire_wheels) × 100
```

## 5. 정답지 회귀테스트 vs 자동생성 (구분 필수)

- **회귀테스트**: 실물 무게(탑 550·냉동기 50·데크 300)를 넣어 E9721 재현
  → 공차 1105/1100, 적차 1190/1445, 조향륜 45.2%, 부하율 70.0/85.0
- **자동생성(운영)**: 탑무게=§3 계산값(407.1) 사용 → 값이 실물과 다른 게 정상
  (같은 치수·상수로 자체 일관성만 만족하면 됨)

## 6. 오픈베드(구조변경 전) 기준값 — 정정

정원 위치 = **1850** (2995 아님), 적재 위치 = 35.
오픈베드 적차 정답 = **1195 / 1440** (1245/1390 아님). ← 이전 지시 정정.
