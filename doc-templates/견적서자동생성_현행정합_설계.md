# 견적서 자동생성 — 현행 코드 정합 + 신규 총견적서 반영 설계

> 입력 정답지: `STEGO-K1_총견적서.xlsx` (입력시트 / 차량견적서 / 옵션DB).
> 현행 코드는 견적서 Ver1.21 기준으로 이미 상당 부분 구현됨. 이 문서는 **매핑 + GAP + 계획**.
> CLAUDE.md 준수(단가·보조금·세율은 DB, 하드코딩 금지).

## 2. 신규 총견적서에 있으나 현행 코드에 없는 것 (GAP — 구현 대상)

현행 = 통합 "실구매가"까지. 신규 총견적서 = **차량/특장 분리 결제 + 할부 + 구매혜택**까지 확장됨.

| # | 항목 | 엑셀 근거 | 현행 |
|---|---|---|---|
| G1 | **할부(PMT)** — 월납입금·총할부금·할부이자 | K17~M24, 이율표 AF/AG | ❌ 없음 |
| G2 | **할부개월수별 이율표** | 옵션DB AF/AG (일시불·36·48·60) | ❌ 없음 (DB화 필요) |

| G4 | **선수금**(비율) → 인도금 | G5·D22·D23 | ❌ 없음 |

| G6 | **구매혜택**: 현대커머셜 할인(70만)·공식 파트너십 할인(1%) | D12·D13·D14 | ❌ 없음 |

## 3. 옵션 매칭 상태 (엑셀 ↔ option_value seed)

대체로 일치. 확인·정정 포인트:
- 엑셀 "냉장/냉동" ↔ code `BODY_REEFER`(냉동). 라벨만 표기 차이.
- 도어: 여닫이/슬라이딩/EV미닫이(냉동전용)/쿠팡미닫이(내장전용) ↔ `DOOR_SWING/SLIDE/EVSLIDE/COUPANG` 매칭.
- 격벽: 그물망/냉장·냉동 이동식/X ↔ `PART_NET/PART_REEFER/PART_NONE` 매칭.
- 엑셀엔 데칼·썬팅·블랙박스·지급품키트 없음(메모에 "서비스"로만) — code엔 옵션 존재. **무게·가격 모두 미반영 방침과 일관**(서류엔 서비스 표기).

## 5. 신규 계산 로직 (GAP 구현 수식)

### 구매혜택 (차량 결제금액 축)
```
현대커머셜_할인 = commercial (DB 상수, 예 700,000)
파트너십_할인   = (차량가격 − 현대커머셜_할인) × 0.01
구매혜택_합계   = 현대커머셜_할인 + 파트너십_할인
차량결제금액    = 차량가격 + 탁송료 − 구매혜택 − 보조금합계
```

### 공채
```
공채할인액 = (면세구분='일반인' AND 지역='서울특별시') ? DB.공채할인액 : 0
```

### 차량/특장 분리 결제 + 할부
```
차량_계약금 = 100,000 (DB)      특장_계약금 = 400,000 (DB)
선수금      = (차량결제 + 특장결제 − 계약금합) × 선수금비율(입력)
인도금      = 계약금 + 선수금
할부원금(총) = (차량결제 − 차량인도금) + (특장결제 − 특장인도금)
이율        = InstallmentRate[할부개월수]        // 일시불=0
월납입금    = PMT(이율/12, 개월수, −할부원금)     // 원리금균등
할부이자    = 월납입금 × 개월수 − 할부원금
```
※ `PMT`는 엑셀 함수 → 백엔드에서 원리금균등상환식 직접 구현.
```
PMT = P × r / (1 − (1+r)^(−n)),  r=월이율, n=개월수, r=0이면 P/n
```

## 6. 검증 (회귀 정답지)

- 기존 fixture(₩32,013,860) 유지.
- **`STEGO-K1_총견적서.xlsx`의 입력시트 조합**을 fixture로 추가 →
  차량결제금액·특장결제금액·인도금·월납입금·총할부금까지 엑셀 값과 일치 확인.
  (엑셀 셀 값 = ground truth. 코드가 재현하도록.)
- 옵션DB 값 하나 바꾸면 견적이 실제로 달라지는지(관리자 CRUD) 확인.

## 7. 작업 순서
1. GAP 계산(구매혜택·공채·계약금·선수금·인도금·할부) → `calcPrice` 확장 or `calcQuote` 신설(차량/특장 분리).
2. `InstallmentRate` 테이블 + `TaxConfig` 공채/계약금 컬럼 추가(백업 후) + seed.
3. 총견적서 조합을 회귀 fixture로 박제 → 엑셀 값 재현 검증.
4. 견적서 PDF 템플릿(quote-pdf.html)을 총견적서 레이아웃(차량/특장/할부/구매혜택)으로 갱신.
5. 옵션DB 관리자 UI(§4 매핑) — 특히 지역보조금 161행 검색·일괄수정, 할부 이율표.
6. 전체 테스트 → 커밋 목록 보여주고 멈춤(push 금지).
