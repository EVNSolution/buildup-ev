## 반영된 기획 포인트

### 레이아웃
- **좌측 고정 · 우측 탭만 스크롤** — 3D 뷰어와 가격바는 항상 보임. 옵션 패널만 내부 스크롤.

### 좌측 — 3D 뷰어 + 가격바
- **3D 임베드 영역** — VIVAR iframe이 들어갈 자리. 현재는 SVG 플레이스홀더. 치수·도면은 VIVAR에서 수신, 견적·하중 계산은 EV& 서버가 담당.
- **가격바 4종** — 차량가 / 보조금 / 실구매가 / **부가세환급후(강조)**. 견적 생성 전에는 값이 흐리게 표시되고, 견적 생성 버튼 클릭 후 실수치로 채워짐.
- **부가세환급후 강조** — 영업 현장에서 고객에게 먼저 보여주는 핵심 숫자. 짙은 배경 + 라임 레이블로 시각 구분.

### 우측 — 옵션 패널 (3탭)
- **탭 1 · 차량 옵션** — 트림 블록 카드 선택 UI. 트림 선택 시 하단에 사양 요약 카드 표시. 적재함 유형은 세그먼트 버튼.
- **탭 2 · 특장** — 탑 종류(내장/냉동탑/냉장탑) · 탑 크기(저상/표준) · 도어 종류 · 도어 추가 · 격벽 · 온도기록계. 종속 제약(내장탑 → 온도기록계 비활성 등)은 option_rule 기반으로 UI 차단.
- **탭 3 · 기타** — 지역(보조금) · 보조금 표시.

### 고객 정보 모달
- **화면 진입 시 모달 먼저 표시** — 고객명·사업자 유형·소상공인·경유차 폐차 여부 입력.
- **건너뛰기 가능** — 건너뛰면 보조금 미반영 참고 견적만 확인. 모달 상단 안내 문구로 명시.
