# buildup-ev 디자인 시스템 v2

> 방향: **macOS 톤**(정제된 여백·헤어라인·부드러운 깊이) / 여유 있는 밀도 / 기존 색체계 유지.
> 적용: `frontend/src/styles/globals.css` 에 CSS 변수 정의 → 컴포넌트는 변수만 참조.

---

## 0. macOS 톤을 만드는 5가지

기존과 가장 크게 달라지는 지점. 이것만 지켜도 분위기가 바뀐다.

| 요소 | 지금 | v2 (macOS 톤) |
|---|---|---|
| 테두리 | `1px solid #E6E8EB` | **`0.5px`** 헤어라인. 굵은 선은 구조를 무겁게 만든다 |
| 그림자 | 없음 | **`0 1px 2px rgba(0,0,0,.04)`** 아주 얕게. 카드가 종이처럼 떠 보임 |
| 제목 자간 | 기본 | **`letter-spacing: -0.01em`** — SF Pro 특유의 조여진 제목 |
| 모서리 | 6~8px | **10px(카드) / 6px(컨트롤)** — 조금 더 둥글게 |
| 탭 | 밑줄·검은 알약 | **세그먼티드 컨트롤** (회색 트랙 + 흰 알약 + 얕은 그림자) |

**폰트**: `Pretendard, -apple-system, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`
★ **Pretendard 자체 호스팅이 1순위**(CDN 의존 금지). 시스템 폰트에 맡기면 기기마다 글자 폭이
달라져 표 헤더가 접히고 버튼 라벨이 줄바꿈된다. woff2 subset · `font-display: swap` ·
weight 400/500/600만 로드. 자세한 내용은 `ui-revamp-plan.md` 0단계.

## 1. 색 (Color)

기존 토큰 유지 + 역할 명확화. **새 색은 추가하지 않는다.**
(예외는 아래 표에 올린 것뿐 — 코드에만 있는 색은 시스템에 먼저 올린 뒤 쓴다.)

### 화면에 흩어져 있던 색 → 토큰 매핑 ★
3단계 정리에서 쓴 표. 새 색을 만들지 않고 **이 표대로만** 옮긴다.

| 화면에 있던 것 | → 토큰 | 뜻 |
|---|---|---|
| `#a12d2d` `#8a3a2f` `#e57373` (빨강 글자) | `--warn` | 오류·경고 |
| `#fdecec` `#fdf1ee` (빨강 배경) | `--warnbg` | 오류 배경 |
| `#f0b8b8` `#f2c9be` (빨강 테두리) | `--warn` + 0.5px | 오류 테두리 |
| `#e65100` `#fff3e0` (주황) | `--warn` / `--warnbg` | 주의 |
| `#2e7d32` `#3d6b28` (초록 글자) | `--dark` | 완료는 **차분하게** — 초록은 시스템에 없다 |
| `#e8f5e9` `#eef7e9` `#f2f6e8` `#f7fadf` (초록·라임 배경) | `--lime-bg` | 성공·선택 배경 |
| `#cfe4c2` `#dce8c2` `#d5e0bf` (초록 테두리) | `--lime` | 성공·선택 테두리 |
| `#1565c0` `#e3f2fd` `#eef2f6` `#5a6b7a` (파랑) | `--dark` / `--card` | 파랑은 시스템에 없다. 버튼은 secondary 로 |
| `#c2c8cf` `#b0b7c0` `#b0b8c0` `#8a929c` `#9aa0a8` (회색 글자) | `--muted` | 보조 텍스트 |
| `#f5f5f5` `#f0f2f4` `#f7f8f3` (회색 배경) | `--card` | 섹션 배경 |
| `#1a1a1a` / `#c8d200` | `--dark` / `--lime` | 같은 값의 하드코딩 |

| 변수 | 값 | 역할 |
|---|---|---|
| `--lime` | `#C8D200` | EV& 브랜드. **선택·활성 표시 전용** (버튼 채움색 아님) |
| `--dark` | `#1A1A1A` | 주 액션 버튼, 강조 텍스트 |
| `--body` | `#333` | 본문 |
| `--muted` | `#8A8F98` | 보조 텍스트·라벨·비활성 |
| `--line` | `#E6E8EB` | 헤어라인 (0.5px로 사용) |
| `--card` | `#F6F7F4` | 카드·섹션 배경 |
| `--bg` | `#FFF` | 페이지 배경 |
| `--warn` | `#B3471F` | 위험 액션·경고 |
| `--warnbg` | `#FFF3E8` | 경고 배경 |
| `--req` | `#C0392B` | **「필수」 표시 전용**. `--warn`(되돌릴 수 없는 동작)과 구분한다 — 아직 안 채운 칸과 삭제가 같은 색이면 무게가 뒤섞인다 |

**파생 (신규)**
| 변수 | 값 | 역할 |
|---|---|---|
| `--lime-bg` | `rgba(200,210,0,.10)` | 선택 항목의 옅은 배경 |
| `--lime-ink` | `#AEB800` | 라임 **글자**용(원색은 흰 바탕에서 흐리다). 대비가 낮아 **큰 숫자 전용** — 실구매가 |
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.04)` | 카드 기본 |
| `--shadow-2` | `0 4px 12px rgba(0,0,0,.08)` | 모달·팝오버 |
| `--track` | `#EFEFF2` | 세그먼티드 컨트롤 트랙 |

## 2. 타이포그래피

12종 → **5단계**.

| 변수 | 크기/굵기 | 자간 | 용도 |
|---|---|---|---|
| `--fs-title` | 20px / 600 | -0.01em | 페이지 제목 |
| `--fs-section` | 15px / 600 | -0.01em | 섹션 제목, 리스트 항목명 |
| `--fs-body` | 14px / 400 | 0 | 본문·입력값·버튼 |
| `--fs-label` | 13px / 500 | 0 | 필드 라벨, 표 헤더 |
| `--fs-caption` | 12px / 400 | 0 | 보조 설명, 공급가, 날짜 |

- line-height: 제목 1.3 / 본문 1.5
- 금액·수량은 `font-variant-numeric: tabular-nums` (자릿수 정렬)
- **굵기는 400/500/600 셋만.** 700 이상은 쓰지 않는다 (macOS는 무겁게 안 씀)

## 3. 줄바꿈·말줄임 규칙 ★

화면이 깨지는 가장 흔한 원인. 요소별로 규칙을 고정한다.

| 대상 | 규칙 | CSS |
|---|---|---|
| **금액·수량·날짜** | 절대 줄바꿈 금지 | `white-space: nowrap` |
| **리스트 제목** (고객명·차종) | 1줄 + 말줄임 | `overflow:hidden; text-overflow:ellipsis; white-space:nowrap` |
| **리스트 부제** (견적번호·지역) | 1줄 + 말줄임 | 위와 동일 |
| **본문 설명·메모** | 자연 줄바꿈, 최대 2줄 후 말줄임 | `display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; overflow:hidden` |
| **버튼 라벨** | 줄바꿈 금지 | `white-space: nowrap` |
| **표 셀** | 헤더는 nowrap, 값은 말줄임 | 위 규칙 조합 |
| **옵션명** | 2줄까지 허용(길면 줄어듦) | `line-clamp:2` |

**한국어 줄바꿈**: `word-break: keep-all` 을 body에 전역 적용.
(단어 중간에서 끊기는 것 방지 — 한글에서 이걸 안 하면 "냉장/냉동 이동식 격" / "벽" 처럼 깨진다)

**말줄임의 전제**: 부모에 `min-width: 0` 이 있어야 flex 안에서 말줄임이 동작한다.

## 4. 적응형 ★ (폭 기준 아님)

**폭으로 기기를 판정하지 않는다.** 태블릿을 폭으로 판단하면 데스크톱으로 오인한다.

```css
/* 세로형 판정 — 가격 블록 가로 → 세로 */
@container (aspect-ratio < 1)   { ... }
/* 터치 판정 — 히트영역 확대, 여백 축소 */
@media (pointer: coarse)        { ... }
```

**검증은 세 가지 형태로**: ① 넓은 데스크톱 ② 태블릿 가로 ③ 세로로 긴 화면

**규칙**
- **컨테이너 최대폭 1440px**, 그 이상 가운데 정렬
- **3D는 항상 16:9** — 컨테이너 쿼리로 계산(`aspect-ratio` 단독 금지). 나머지가 3D에 맞춤
- **페이지 전체 스크롤 없음** — 화면마다 스크롤 주체를 하나만 지정 (`ui-revamp-plan.md` §1-1)
- 관리자 표: 좁아지면 가로 스크롤. **컬럼을 숨기지 말 것** — 데이터 누락으로 오해됨
- 터치 히트영역 **44×44px** (표 내부 버튼도 예외 없음)

## 4-1. hover 금지 규칙 ★

**정보·기능을 hover에 숨기지 않는다.** 태블릿에서는 영영 볼 수 없다.

- hover는 시각 피드백(테두리 톤 변화) 정도로만 — 없어도 기능에 지장 없어야 함
- 접히는 정보(트림 사양 등)는 **명시적 토글 버튼**으로
- 툴팁이 유일한 설명 수단이 되면 안 됨 — 상시 캡션 병행

## 4-2. 고객 노출 구분 ★

상담 화면은 **고객이 함께 본다.**

- **노출 가능**: 3D, 옵션, 해당 건 가격·보조금, 사양표
- **내부 전용**: 다른 고객 견적 목록, 영업 실적, 계정 관리, 원가
- 컨피규레이터 화면에 **다른 고객의 이름·연락처·금액이 나타나지 않는다**

## 4-3. 저대비 금지

야외·매장 조명 고려.
- **라임 배경 위 흰 글씨 금지.** 라임 위 텍스트는 `--dark`
- 라임 텍스트는 흰 배경에서만
- 본문 대비 4.5:1 이상

## 5. 간격 (Spacing)

**4의 배수 6단계**.

| 변수 | 값 | 용도 |
|---|---|---|
| `--sp-1` | 4px | 아이콘-텍스트 |
| `--sp-2` | 8px | 요소 내부 |
| `--sp-3` | 12px | 폼 필드 사이 |
| `--sp-4` | 16px | 카드 패딩 |
| `--sp-5` | 24px | 섹션 사이, 페이지 좌우 여백 |
| `--sp-6` | 32px | 페이지 상하 여백 |

## 6. 모서리 (Radius)

| 변수 | 값 | 용도 |
|---|---|---|
| `--r-sm` | 6px | 입력창, 버튼, 뱃지 |
| `--r-md` | 10px | 카드, 패널, 옵션 박스 |
| `--r-pill` | 999px | 세그먼티드 컨트롤, 카운트 뱃지 |

## 7. 버튼

| 종류 | 스타일 | 사용처 |
|---|---|---|
| **Primary** | `--dark` 배경, 흰 글씨 | 저장·조회·발송 — 화면당 1개 원칙 |
| **Secondary** | 흰 배경, `0.5px --line`, `--shadow-1` | 사양 보기, 이력, 취소 |
| **Danger** | 흰 배경, `--warn` 테두리·글씨 | 되돌리기, 삭제 |
| **Disabled** | `--card` 배경, `--muted` 글씨 | 조건 미충족 |

- 크기: 높이 36px / 패딩 `0 var(--sp-4)` / `--fs-body` / `--r-sm`
- 작은 버튼(표 내부): 28px / `0 var(--sp-3)` / `--fs-caption`
- `sm` 브레이크포인트에서 44px

## 8. 세그먼티드 컨트롤 (탭)

macOS 톤의 핵심. 현재 "검은 알약"·"밑줄" 혼용 → 하나로 통일.

```
트랙:   --track 배경, --r-pill, 패딩 2px
아이템: 투명 배경, --fs-label, --muted
선택됨: 흰 배경, --r-pill, --shadow-1, --dark 글씨
```
적용: 역할 전환(영업·관리·특장), 컨피규레이터 3탭, 관리자 7탭

## 9. 선택 상태 (옵션 카드)

```
기본:   흰 배경 + 0.5px --line + --shadow-1
선택됨: --lime 2px 테두리 + --lime-bg 배경 (패딩 -1px 보정)
비활성: --card 배경 + --muted 글씨
누름:   scale(.97) — 누를 때 90ms / 뗄 때 260ms 스프링(비대칭)
hover:  테두리 톤 변화만. 없어도 무방 (§4-1)
```

## 10. 리스트 아이템

```
패딩 var(--sp-4) / 흰 배경 / 0.5px --line / --r-md / --shadow-1
항목 사이 var(--sp-3) / 터치 시 히트영역 44px 이상
```
**긴 값 내성**: 고객명 20자·주소 40자·상호 30자·금액 9자리에서 밀리지 않아야 한다.
금액·날짜 `nowrap` + `tabular-nums`, 이름·주소 1줄 말줄임(부모 `min-width:0`).
좌: 제목(`--fs-section`, 말줄임) + 부제(`--fs-caption`, `--muted`, 말줄임)
중: 상태 뱃지
우: 금액(`--fs-section`, tabular-nums, nowrap) + 날짜(`--fs-caption`)

## 11. 빈 상태

```
중앙 정렬, 상하 패딩 var(--sp-6) × 2
1줄 제목 (--fs-section)      "아직 저장된 견적이 없습니다"
2줄 설명 (--fs-body, --muted) "컨피규레이터에서 옵션을 선택하고 견적을 저장해 보세요"
3줄 Primary 버튼 (선택)       "컨피규레이터로 이동"
```
문구는 사과가 아니라 **다음 행동 안내**로 쓴다.

## 12. 상태 뱃지

```
패딩 2px 10px / --r-pill / --fs-caption / 굵기 500 / nowrap
진행중: --lime-bg + --dark
완료:   --card + --muted
대기:   흰 배경 + 0.5px --line + --muted
경고:   --warnbg + --warn
```

## 13. 적용 원칙

1. 컴포넌트에 **숫자를 직접 쓰지 않는다.** 변수만 참조.
2. 새 값이 필요하면 시스템에 먼저 추가한다.
3. **화면 단위로 순차 적용.** 한 번에 전부 바꾸지 않는다.
4. 순서: 공통(헤더·버튼·탭) → 영업 컨피규레이터 → 견적·주문 목록 → 관리자 → 특장사
5. 각 화면 적용 후 **3개 브레이크포인트에서 확인**한다.
