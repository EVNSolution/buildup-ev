# Claude Code 킥오프 프롬프트 모음 (buildup-ev)

> 사용법: 맥 터미널에서 작업 폴더로 가서 `claude` 실행 → 아래 프롬프트를 순서대로 붙여넣기.
> git 명령은 외울 필요 없음 — 하고 싶은 걸 말하면 Claude Code가 브랜치·커밋·푸시·PR을 대신 함.

---

## 0. 사전 (한 번만)
- GitHub 로그인 확인: 터미널에 `gh auth status` (이미 완료)
- 작업 폴더 정하기 (예: `~/dev`). 거기서 `claude` 실행.

---

## 1. 첫 세션 — 저장소 + 구조 + 문서 (복붙)

```
나는 buildup-ev 라는 전기 특장차 웹 플랫폼을 만들려는 PM이야. 개발 경험은 적으니 git과 구조를 네가 주도해줘. 지금은 코드는 짜지 말고 저장소 뼈대와 문서까지만.

순서:
1. gh로 private 저장소 'buildup-ev' 생성하고 clone해줘. (이미 있으면 알려줘)
2. '~/Documents/02. EV&/05. Buildup-EV/00. 기획/' 안의 문서 전부(.md, .xlsx, .pptx)를 repo의 docs/ 로 복사해줘.
3. docs/CLAUDE.md 를 repo 루트로 옮겨줘(또는 복사). 이게 프로젝트 컨텍스트야 — 먼저 읽어.
4. 모노레포 폴더 구조 생성: db/{schema,seed,templates}, backend/, frontend/, app/, shared/ — 각 폴더에 .gitkeep 또는 짧은 README.
5. db/templates 로 DB 구축 엑셀(buildup-ev_DB구축템플릿_v0.2.xlsx)을 옮겨줘.
6. .gitignore 생성(node_modules, .env, dist, build, .DS_Store, *.log 등). .env.example 빈 양식도.
7. 루트 README.md: 프로젝트 한 줄 소개 + 폴더 구조 + "스펙은 docs/ 참조".
8. 전부 git add → 커밋("chore: 프로젝트 초기 구조와 문서") → 푸시.

진행 전에 계획(어떤 파일/구조 만들지)을 먼저 보여주고 확인받아줘.
```

## 2. DB 데이터 → CSV/스키마 (엑셀 채워진 뒤)

```
db/templates/buildup-ev_DB구축템플릿_v0.2.xlsx 가 채워졌어.
1. 이 엑셀을 읽어서 시트별로 db/seed/{시트명}.csv 로 변환하는 스크립트(scripts/xlsx_to_csv)를 만들고 실행해줘. (헤더는 영문키 기준, 예시/안내 행은 제외)
2. docs/DB스키마 문서를 참고해 db/schema/001_init.sql (테이블 생성 DDL, PK/FK 포함)을 만들어줘. DBMS는 (배포담당과 정한 것)으로.
3. feature/db-seed 브랜치에서 작업하고, 커밋·푸시·PR까지.
변경 잦은 데이터니, 앞으로 엑셀 갱신 → 스크립트 재실행 → CSV 갱신 흐름으로 가자.
```

## 3. 백엔드 첫 모듈 — 옵션·견적 API

```
feature/quote-engine 브랜치 만들고 시작하자.
docs/ 기획서·DB스키마·견적서 엑셀을 정답지로 삼아 backend/ 에 견적 API를 만들어줘.
- 입력: 차종 + 선택 옵션값들 + 고객정보(사업자유형·소상공인·지역·폐차)
- 출력: 공급가액 → 부가세 → 차량가 → 보조금(국고+지방+소상공인) → 부가세환급후 → +등록비+기타 = 실구매가
- 도어가는 룰((선택−기본 단품)+추가시 단품), 값은 DB(db/seed)에서.
- 회귀 테스트 1개: '범석환 케이스 → 실구매가 ₩46,471,818' 가 나오는지 검증.
작게 커밋하면서 가고, 끝나면 PR 올려줘.
```

## 4. 백엔드 — 하중계산 모듈

```
feature/loadcalc 브랜치.
docs/ 하중계산기 엑셀(PV5_하중계산기_TS모방.xlsx)의 로직을 backend/loadcalc API로 옮겨줘.
- 전축=ΣW·a/L, 후축=ΣW·(L−a)/L, 전축 추가하중 5kg 올림
- 타이어 부하율 = 축하중/(허용하중×바퀴수)×100, 조향륜분포율 = 적차전축/총중량×100
- 법규 적합성 2-check(최대허용제원 이내 / 하중 부적합 없음) → 적합여부 반환
- 검증: PV5 케이스가 엑셀 결과와 일치하는지 테스트.
```

```
- 옵션 패널 3분류(차량옵션/특장/내부옵션) — 옵션은 백엔드 API로 받아 렌더, 종속옵션(option_rule)은 비활성 처리
- '견적생성' 누르면 백엔드 견적 API 호출 → 실구매가/부가세환급후 강조 표시
- 고객정보 입력 + 견적 저장
스택은 (정한 것). 백엔드 API 계약 먼저 맞추고 진행해줘.
```
